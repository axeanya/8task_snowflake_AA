# 8task_Spark_AA
This module provides a practical introduction to Snowflake as a columnar database, focusing on its key features through the creation of a small Data Warehouse (DWH). You will design a multi-layered DWH and implement an ETL/ELT pipeline orchestrated by Airflow, loading data through various methods including procedures, streams, and optionally Snowpipe for external stages. The module also covers advanced Snowflake features such as implementing logging with audit tables, utilizing time-travel for DDL/DML queries, and configuring Secure Views with Row-Level Security, with an optional component for BI tool integration.
